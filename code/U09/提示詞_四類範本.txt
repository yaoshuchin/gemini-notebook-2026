========== ① 空間生成器（房間、室內設計）==========
請在這個資料夾做一個「我的房間生成器」網頁，給學生設計理想房間用。
一、範本：6 種房間範本——臥室、書房、客廳、套房、宿舍、遊戲室
二、選項：用下拉選單和滑桿調整——房間寬度與深度（公尺）、天花板高度、門窗位置、家具（床、書桌、椅子、書櫃、沙發，可加可刪，點選後用滑桿調位置與旋轉）
三、隨機：「隨機生成」按鈕隨機擺放家具；顯示種子碼，輸入同一個種子碼可以重現
四、預覽：three.js 3D 即時顯示，旁邊一張 2D 平面圖；彩色／線稿切換
五、匯出：下載 PNG；複製分享連結
六、其他：全站繁體中文、手機也能用；單一 index.html，three.js 用 CDN 載入
七、完成後：自己用瀏覽器測試，Console 沒有錯誤、每個按鈕都能用，再告訴我怎麼打開

========== ② 場景生成器（多主題場景＋物件庫）==========
請在這個資料夾做一個「故事場景生成器」網頁，給寫故事、畫漫畫的學生找背景用。
一、範本：4 大類各 3 種場景——室內（教室、咖啡店、圖書館）、街道（老街、夜市、巷弄）、奇幻（城堡大廳、魔法森林、地下城）、科幻（太空艙、實驗室、未來城市）
二、選項：物件庫可以加入或刪除物件（至少 30 種）、時段（早上／黃昏／夜晚）、配色主題（至少 6 種）、鏡頭角度（正面、俯視、仰視、角落）
三、隨機：「隨機生成」按鈕在目前場景隨機補上 5 件物件；顯示種子碼
四、預覽：three.js 3D 即時顯示；彩色／線稿切換
五、匯出：下載 PNG；匯出 JSON 存檔、匯入 JSON 接著編輯
六、其他：全站繁體中文、手機也能用；單一 index.html，three.js 用 CDN 載入
七、完成後：自己用瀏覽器測試，Console 沒有錯誤、每個按鈕都能用，再告訴我怎麼打開

========== ③ 轉蛋型生成器（按一下就隨機出結果）==========
請在這個資料夾做一個「角色設定轉蛋機」網頁，給學生寫故事時找靈感用。
一、範本：5 種故事類型——校園、奇幻、科幻、武俠、偵探；每種有自己的職業、個性、外型、口頭禪清單（每項至少 12 個）
二、選項：先選故事類型；可以「鎖定」某一項（例如鎖定職業），只轉其他項目
三、隨機：一個轉蛋機外型的大按鈕，按下有扭蛋掉落動畫，出現一張角色卡；顯示種子碼
四、預覽：角色卡用 2D 畫面呈現（名字、職業、個性、外型、口頭禪、代表色）
五、匯出：下載角色卡 PNG；「收藏」保留在頁面右側清單（存在瀏覽器）
六、其他：全站繁體中文、手機也能用；單一 index.html，不需要安裝
七、完成後：自己用瀏覽器測試，Console 沒有錯誤、每個按鈕都能用，再告訴我怎麼打開

========== ④ 素材生成器（對話框、效果線、字卡）==========

一、範本：8 種對話框——圓形、橢圓、雲朵（想法）、爆炸（大叫）、方框（旁白）、虛線（小聲）、鋸齒（電話）、多重（重疊）
二、選項：用滑桿調整——寬、高、尾巴方向與長度、線條粗細、字體大小；文字可輸入，可選直書或橫書
三、隨機：「隨機生成」按鈕隨機挑形狀與參數；顯示種子碼
四、預覽：2D 畫布即時顯示
五、匯出：下載透明背景 PNG；下載 SVG
