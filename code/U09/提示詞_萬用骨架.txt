【萬用生成器提示詞骨架】把＿＿＿換成你的內容，整段貼給 Claude Code 或 Codex
（一個生成器 = 範本 + 選項 + 隨機 + 預覽 + 匯出）

請在這個資料夾做一個「＿＿＿生成器」網頁，給＿＿＿用來＿＿＿。
一、範本：＿種＿＿範本——（列出每一種的名稱）
二、選項：用下拉選單和滑桿調整——（列出 3～5 個可以調的東西，例如數量、顏色、時段、排列）
三、隨機：一個大大的「隨機生成」按鈕，每按一次隨機組合一個結果；畫面顯示「種子碼」，輸入同一個種子碼可以重現同一個結果
四、預覽：（2D 畫面／three.js 3D）即時顯示結果；（可選）彩色／線稿切換
五、匯出：「下載 PNG」存目前畫面；「複製分享連結」把目前設定放進網址
六、其他：全站繁體中文、手機也能用；做成單一 index.html，需要的函式庫用 CDN 載入，不需要安裝任何東西
七、完成後：自己用瀏覽器測試，Console 沒有錯誤、每個按鈕都能用，再用三行字告訴我做了什麼、怎麼打開

【寫好的小技巧】
1. 範本、選項一定要「列出名稱」，AI 才不會自己亂湊
2. 第七點很重要：要它自己測過再交給你
3. 先做出能用的版本，再一次加一個功能（見 提示詞_改版追加.txt）
4. 參考別人的網站可以，但要用自己的話描述功能，不要叫 AI 整站複製或翻譯後上線
