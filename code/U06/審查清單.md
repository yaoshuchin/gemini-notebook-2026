# 帶回家的審查機制（每次都照做）

| 階段 | 一定要做的檢查 |
|---|---|
| 上傳資料後 | 紅底來源處理掉；表格類資料點一個引用，確認讀得對；重要表格另附文字版或 CSV |
| 問答與成品 | 數字、日期、條次點引用核對；生成前取消勾選「記事」類來源；成品逐句看有沒有「原文沒寫的字」 |
| 規格書 | 另一個 AI 只挑錯不改檔 → 人工裁決表，每項寫「採納／部分採納／不採納」與理由 |
| 程式 | 自己的測試全過 → 另一個 AI 設計邊界測試 → 修正時禁止修改測試檔 → git diff 確認改動範圍 |
| 交付前 | 人看過每一頁：去贅字、贅述、錯字；確認沒有畫蛇添足的功能或規則 |

## 本課實際遇到的四個錯
1. PDF 表格兩列被擠成一行 → AI 判定特休「規章漏列」（其實沒漏）。修正：用「複製的文字」補文字版。
2. 資料表把一次問答存成的記事當成規定。修正：生成前取消勾選記事。
3. 資訊圖表寫出規章沒寫的「線上報帳」。修正：成品逐句對原文。
4. 程式把「代碼 122:00」當成深夜 22:00。修正：Codex 邊界測試抓到，Claude Code 改 1 行。
