課前須知

課程用哪個版本的 Claude、Codex？以 CLI（指令列）版本為優先。教材實機版本：Claude Code 2.1.296、Codex CLI 0.159.0。
沒有程式背景可以上嗎？要懂 JavaScript、Python 嗎？可以，但需要有規劃與撰寫文字的基礎能力。不需要懂 JavaScript 或 Python，只要知道技術可以做到哪些事。
會教怎麼驗證輸出、檢查邏輯嗎？會。AI 也會錯，要人工看過所有頁面、去贅字錯字，重點是檢查邏輯有沒有畫蛇添足；用不同 AI 交叉驗證，設計成審查機制（U04～U06）。
想買筆電，怎麼選？老師建議 RTX 4090 以上的獨立顯示卡為佳。課程工具都在雲端運算，上課當下一般筆電即可操作。
